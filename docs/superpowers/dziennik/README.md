# Dziennik sesji

Jeden plik na dzień (`RRRR-MM-DD.md`). Każdy wpis ma cztery nagłówki:

- **Co zrobione:** polecenia, pliki, funkcje.
- **Decyzje:** z uzasadnieniem.
- **Otwarte wątki:** co zostało do podjęcia następnym razem.
- **Błędy:** co poszło źle i jak to rozwiązano.

Na starcie rozmowy czytaj `../stan-projektu.md` i najnowszy plik tutaj, nie cały folder. Wpisy z 16–23.11.2026 odtworzono 23.11 z historii gita, specyfikacji, planów i listy odłożonych uwag. Szczegóły rozmów sprzed 22.11 mogą być niepełne.
